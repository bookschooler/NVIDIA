1단계: VS Code 설치하기 (Windows)
공식 웹사이트 접속: 브라우저를 열고 VS Code 공식 홈페이지로 이동합니다.

다운로드: 화면에 보이는 [Download for Windows] 버튼을 눌러 설치 파일을 받습니다.

설치 진행: 다운로드한 .exe 파일을 실행합니다.

꿀팁: 설치 과정 중 '추가 작업 선택' 창이 나오면 [체크박스 옵션] 중에서 
Code로 열기(Open with Code) 액션을 Windows 탐색기 상황에 맞는 메뉴에 추가 항목들을 
모두 체크해 주는 것이 나중에 폴더를 열 때 매우 편리합니다. ( 그냥 모두 체크 )
================================================================

2단계: WSL 및 Linux(Ubuntu) 설치 확인
이미 WSL과 Ubuntu가 설치되어 있다면 3단계로 넘어가셔도 좋습니다.

시작 메뉴에서 PowerShell을 관리자 권한으로 실행합니다.
다음 명령어를 입력하여 WSL과 기본 리눅스(Ubuntu)를 설치합니다.

PowerShell
wsl --install
설치가 완료되면 컴퓨터를 재부팅합니다.

재부팅 후 자동으로 우분투 터미널 창이 뜨면서 리눅스에서 사용할 
Username(ID)과 Password를 설정하라고 나옵니다. 기억하기 쉬운 값으로 설정해 주세요.
====================================================================

3단계: VS Code에 'WSL 확장 프로그램' 설치하기
윈도우에 설치된 VS Code가 리눅스(WSL) 내부를 들여다볼 수 있도록 다리를 놓아주는 작업입니다.

설치한 VS Code를 실행합니다.
왼쪽 사이드바에서 블록 모양 아이콘인 Extensions(확장) 탭을 클릭합니다 (단축키: Ctrl + Shift + X).
검색창에 WSL을 검색합니다.
Microsoft에서 만든 WSL (예전 이름은 Remote - WSL) 확장 프로그램을 찾아 [Install] 버튼을 누릅니다.
===================================================================

4단계: VS Code를 WSL 환경으로 접속하기
VS Code 안에서 바로 켜기
VS Code 왼쪽 최하단 구석을 보면 파란색(또는 초록색)의 작은 원격 연결 아이콘 ><이 보입니다.

이 아이콘을 클릭한 뒤, 상단에 뜨는 메뉴에서 [Connect to WSL] (또는 [New WSL Window])을 선택합니다.

성공 확인법: VS Code 왼쪽 아래에 **WSL: Ubuntu**라는 문구가 표시되면 리눅스 원격 접속에 성공한 것입니다!
=========================================================================

5단계: WSL 전용 파이썬 인터프리터 연동하기 (Python 기준)
리눅스 내부에 있는 파이썬을 인식시키는 최종 단계입니다.

WSL이 연결된 VS Code 창에서 다시 Extensions(확장) 탭(Ctrl + Shift + X)을 엽니다.

Python을 검색합니다.

Microsoft에서 만든 Python 확장을 설치

왼쪽 탐색기 버튼클릭
Open Folder 선택
위 창에서  /home/본인/가상환경폴더 선택    예) /home/sckit/tf_env  
하고 OK 

왼쪽 맨 아래  톱니바뀌 --> 세팅 --> Text Editor 에서 폰트 설정

가상환경 탐색기 창에서  빈곳 위치에서 오른쪽 마우스 클릭-->새폴더 생성
새폴더에서 새파일 생성
